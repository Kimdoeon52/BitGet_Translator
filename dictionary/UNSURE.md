# 확신 없는 용어 (사전 미등록)

여기 있는 단어는 **ko.json에 넣지 않았다.** 문맥에 따라 뜻이 갈리거나, Bitget 화면에서 실제로 어떤 의미로 쓰이는지 확인이 필요한 것들이다. 실제 화면에서 확인한 뒤 결정하면 ko.json으로 옮긴다.

## 미등록: 뜻이 문맥에 따라 갈림

| 원문 | 후보 | 문제 | 확인할 것 |
|---|---|---|---|
| Change | 변동률 / 변경 | 마켓 목록 열에서는 변동률(%), 설정 화면에서는 "변경" 버튼일 수 있음. 1차 수집에서 확인됨 | 어느 화면에서 나오는지 |
| Value | 가치 / 주문 가치 / 평가 금액 | 주문 패널에서는 명목 가치(notional). 1차 수집에서 확인됨 | 주문 패널 위치 |
| Order Cost | 주문 증거금 / 주문 비용 | Cost와 같은 문제. 1차 수집에서 확인됨 | |
| Single | 단일 자산 (증거금 모드) / 단방향 | Multi-assets는 3차 수집으로 확인돼 등록함. 단독 "Single"은 미결제약정 툴팁의 "Single: sum of one side"처럼 다른 뜻으로도 쓰임 | 노출 위치 |
| Closed | 종료됨 / 휴장 | 포지션 내역의 상태값이면 "종료됨"이지만, 주식 무기한(stock perps)의 장 상태면 "휴장" | 노출 위치 |
| Margin Risk Ratio | 증거금 위험 비율 | 마진 거래 화면. Margin Ratio(증거금 비율)와 정의가 같은지 확인 필요 | |
| Spot Available | 현물 사용 가능 | 어느 잔고를 뜻하는지 | |
| Instrument | 상품 / 종목 | | |
| Quote Currency | 호가 통화 / 견적 통화 | 거래쌍의 뒤쪽 통화(USDT) | |
| Position Tier(s) | 포지션 구간 / 레버리지 구간 | 규모별 최대 레버리지 표 | |
| Earn | 예치 / 언 / 수익 상품 | 상단 메뉴 상품명 | |
| Max/Min. Single Order Amount | 1회 최대/최소 주문 금액(수량?) | Amount 문제와 같음. Quantity 버전은 등록함 | |
| Queue 1 / Counterparty 1 | 동일 방향 1호가 / 상대 1호가 | BBO 하위 옵션. 내 쪽 최우선 호가인지 상대 쪽인지에 따라 즉시 체결 여부가 달라짐. **주문 결과에 직접 영향** | BBO 드롭다운 옵션 전체 |
| Preset Order Price | 예약 주문 가격 / 실행 가격 | 익절/손절 트리거 후 넣을 주문 가격으로 추정 | 익절/손절 창 |
| Flat | 보합 / 포지션 없음 | 2차 수집에서 확인. 시세 변동 0인지 포지션 상태인지 불명 | 노출 위치 |
| Show Current | 현재 심볼만 보기 | 필터 체크박스로 추정 | |
| Position :, Account : 등 | 롱/숏 비율 페이지 데이터 라벨 | 데이터 페이지 전용, 우선순위 낮음 | |
| Amount | 수량 / 금액 | 현물 주문 패널에서는 코인 수량, 이체/출금 화면에서는 금액. "수량"으로 통일하면 USDT 입력칸을 수량으로 착각할 수 있음 | 주문 패널에서 단위 표시가 옆에 붙는지 |
| Size | 수량 / 규모 / 포지션 크기 | 포지션 테이블에서 코인 수량인지 USDT 가치인지 설정에 따라 다를 수 있음 | 포지션 탭 헤더와 단위 |
| Total | 총액 / 합계 / 누적 | 주문 패널에서는 USDT 총액, 호가창에서는 **누적 수량** | 호가창 헤더인지 주문 패널인지 |
| Cost | 비용 / 주문 증거금 | 선물 주문 패널에서 주문에 필요한 증거금을 뜻함. "비용"은 수수료로 오해될 수 있음 | 주문 패널 하단 표시 |
| Max Open | 최대 진입 가능 / 최대 주문 가능 | 수량 단위(코인/USDT)가 붙는지 | |
| Equity | 순자산 / 자산 가치 / 평가 자산 | 미실현 손익 포함 여부에 따라 의미가 다름 | 자산 화면 정의 |
| Funding | 펀딩 계정 / 펀딩비 | 자산 화면에서는 계정 이름(입출금용 계정), 선물 화면에서는 펀딩비 | 어느 화면에서 나오는지 |
| New | 신규 / 대기 / 새 상장 | 주문 상태 "New"(접수됨)와 상장 배지 "New"가 같은 단어 | 주문 내역 상태값인지 |
| Flash Close | 즉시 시장가 종료 / 플래시 종료 | Bitget 고유 기능. 포지션 전량을 시장가로 즉시 종료. **위험 버튼이라 정확한 번역 + 병기 필요** | 부분 종료 옵션 유무 |
| Reverse | 포지션 반전 / 반대 포지션 | 기존 포지션을 종료하고 반대 방향으로 진입. **위험 버튼** | 동작 확인 후 critical로 등록 |
| Depth | 뎁스 / 호가 깊이 | 차트 탭 이름 | |
| Convert | 간편 교환 / 환전 | | |
| Callback Rate | 콜백 비율 / 되돌림 비율 | 트레일링 스탑 설정값 | |
| Trade | 거래 / 체결 | 상단 메뉴 "Trade"(거래)와 "Trades"(체결 목록) | |

## 등록했지만 문맥 충돌이 있음

사전에는 들어가 있다. 실제 사용에서 문제가 되면 아래처럼 대응한다.

| 원문 | 현재 번역 | 충돌 | 대응 방안 |
|---|---|---|---|
| Close | 종료 (Close) | 모달/팝업의 "닫기" 버튼도 "종료 (Close)"로 표시됨 | 병기 덕분에 의미 파악은 됨. 문제가 크면 셀렉터 기반 문맥 규칙 도입 (다음 단계) |
| Open | 진입 (Open) | "Open"이 단독으로 다른 뜻(열기 등)으로 쓰이는 경우 | 수집 모드로 실제 노출 위치 확인 |
| Margin | 증거금 | 상단 메뉴의 상품명 "Margin"(마진 거래)도 "증거금"으로 표시됨 | 상단 메뉴는 거래와 무관하므로 우선 감수 |
| Mark Price | 시장 평균가(마크 가격) | 마크 가격은 단순 "시장 평균"이 아니라 인덱스 가격 + 펀딩 베이시스로 계산한 공정가. "평균가"라는 표현이 체결 평균가(Avg. Price → 평균가)와 헷갈릴 수 있음 | 요구사항대로 유지. 대안: "마크 가격(청산 기준가)" |
| TP / SL | 익절 / 손절 | 2글자 약어라 다른 의미와 겹칠 가능성은 낮지만 0은 아님 | 수집 모드로 확인 |

## 엔진 확장 후보

| 패턴 | 예 | 제안 |
|---|---|---|
| ~~단위/개수 접미사~~ | `Positions (0)`, `Price (USDT)` 등 | **적용 완료** (2026-11-10). README "접미사 규칙" 참고 |
| 라벨: 값 | `Limit: 1,000,000 USDT`, `Market: 742` | 같은 노드에 값이 들어 있음. 선물 정보 페이지 전용이라 우선순위 낮음 |
| 콜론 접미사 | `Available:` | 끝의 `:`만 떼고 매칭한 뒤 다시 붙이는 규칙 |
