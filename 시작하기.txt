Bitget KO (테스트 버전 0.4.0)
================================

Bitget 웹 거래 화면의 영어 메뉴와 버튼을 한국어로 바꿔 보여주는 크롬 확장입니다.
번역기나 AI를 쓰지 않고, 미리 만든 용어집에 있는 단어만 바꿉니다.

  예) Open Long   → 롱 진입 (Open Long)
      Limit       → 지정가 (Limit)
      Liq. Price  → 강제 청산가
      Positions (2) → 포지션 (2)
      1.41B       → 14.1억,   30K → 30,000

[ 꼭 알아두세요 ]

  * 주문 직전에는 버튼 괄호 안의 영어 원문과 수량, 가격을 꼭 같이 확인하세요.
    아직 테스트 버전이라 번역이 빠진 곳이나 어색한 곳이 있을 수 있습니다.
  * 화면 글자만 바꿉니다. 주문, 클릭, 입력값에는 영향을 주지 않습니다.
  * 용어 기준: 포지션 Close = "종료",  "청산"은 강제 청산(Liquidation)에만 씁니다.
  * 바뀐 글자에 마우스를 올리면 영어 원문이 나옵니다.
  * 이상하면 확장 아이콘 → "번역" 끄기를 누르면 바로 영어 원래 화면으로 돌아갑니다.


1. 설치 (처음 한 번)
--------------------
  1) 이 압축 파일을 원하는 곳에 풀어 둡니다. (풀어 둔 폴더는 지우면 안 됩니다)
  2) 크롬 주소창에  chrome://extensions  입력
  3) 오른쪽 위 "개발자 모드" 켜기
  4) "압축해제된 확장 프로그램을 로드합니다" 클릭
     → 풀어 둔 폴더 안의 bitget-ko-v0.4.0 폴더 선택 (manifest.json 이 들어 있는 폴더)
  5) 주소창 오른쪽 퍼즐 모양 아이콘 → Bitget KO 옆 핀 눌러서 고정
  6) Bitget 탭을 새로고침하면 적용됩니다.


2. 확장 아이콘 메뉴
-------------------
  번역       : 끄면 바로 영어로 돌아갑니다
  원문 병기  : 주문 버튼 뒤의 (Open Long) 같은 영어 표시. 끄면 한국어만
  숫자 단위 한국식 : 1.41B → 14.1억, 1.5M → 150만, 30K → 30,000
               * 환율 환산이 아니라 단위 표기만 바꿉니다 (USDT는 USDT, BTC는 BTC 그대로)
               * 마우스를 올리면 원래 값이 보입니다. 끄면 원래 표기로 돌아갑니다
               * 차트의 1M(1개월), 15m(15분) 같은 기간 버튼은 바꾸지 않습니다
  라벨 수집  : 번역이 안 된 영어 단어를 모아 둡니다 (아래 3번)


3. 번역 안 된 단어 보내주기 (도와주면 좋아요)
--------------------------------------------
  1) 아이콘 메뉴에서 "초기화" 두 번 누르기 → "라벨 수집" 켜기
  2) 평소처럼 선물 거래 화면에서
     포지션 / 미체결 / 내역 탭, 레버리지, 증거금 모드, 익절/손절 창 등을 한 번씩 열어보기
  3) 아이콘 메뉴 → "JSON 내보내기" → 받아진 파일을 보내주세요
  4) 다 했으면 "라벨 수집" 끄기

  * 이메일 주소, 금액, 숫자, 코인 이름은 자동으로 빠집니다.
  * 영어로 남은 화면이나 이상한 번역은 스크린샷으로 보내줘도 됩니다.


4. 업데이트
-----------
  [ 번역 용어 업데이트: 자동 ]
  * 용어집은 온라인으로 자동 업데이트됩니다. 따로 할 일이 없습니다.
  * 1시간에 한 번 확인합니다. 바로 받고 싶으면 아이콘 메뉴 아래쪽 "지금 확인"을 누르세요.
  * 메뉴에 "사전 v3 (온라인 …)"처럼 현재 용어집 버전이 표시됩니다.
  * 롱/숏, 진입/종료 같은 주문 버튼 번역은 안전을 위해 온라인으로 바뀌지 않습니다.

  [ 프로그램 업데이트: 새 압축 파일을 받았을 때만 ]
  1) 새 파일로 기존 폴더 내용을 덮어쓰기
  2) chrome://extensions → Bitget KO 카드의 새로고침(↻) 버튼
  3) 열려 있는 Bitget 탭 전부 새로고침
