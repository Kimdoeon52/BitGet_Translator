# Bitget KO

Bitget 웹 거래 화면(bitget.com)의 영어 UI 라벨을 **용어 사전 기반 1:1 치환**으로 한국어로 표시하는 크롬 확장입니다.

- 번역 API나 AI를 쓰지 않습니다. `dictionary/ko.json`에 있는 라벨만, 텍스트 전체가 정확히 일치할 때만 바꿉니다.
- 롱/숏, 지정가/시장가, 진입/종료 같은 주문 버튼은 `롱 진입 (Open Long)`처럼 **원문을 함께 표시**합니다.
- 바꾼 라벨에 마우스를 올리면 원문이 툴팁으로 나옵니다.
- 화면에 보이는 글자만 바꿉니다. 클릭, 입력값, 주문 동작에는 영향을 주지 않습니다.

> ⚠️ **번역은 보조 수단입니다.** 주문 직전에는 버튼 괄호 안의 원문과 수량·가격을 반드시 확인하세요. 사전에 없는 라벨은 영어 그대로 남고, Bitget이 화면을 개편하면 일부 라벨이 번역되지 않을 수 있습니다.

## 설치

1. 이 폴더를 PC에 둡니다 (다운로드 또는 복사).
2. 크롬 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`manifest.json`이 있는 폴더)를 선택합니다.
5. 주소창 오른쪽 퍼즐 아이콘에서 **Bitget KO**를 고정해 두면 팝업을 열기 편합니다.
6. bitget.com 거래 화면을 열면 바로 적용됩니다. 이미 열려 있던 탭은 새로고침하세요.

## 팝업 메뉴

| 항목 | 기본값 | 설명 |
|---|---|---|
| 번역 | 켬 | 끄면 바뀐 라벨이 즉시 원문으로 돌아갑니다 |
| 원문 병기 | 켬 | 주문 버튼 등 핵심 라벨 뒤에 `(Open Long)` 원문 표시. 끄면 한국어만 |
| 숫자 단위 한국식 | 켬 | 축약 숫자를 한국식으로 표시: `30K` → `30,000`, `1.5M` → `150만`, `1.41B` → `14.1억`. 마우스를 올리면 원래 값 표시 |
| 라벨 수집 | 끔 | 사전에 없는 영어 라벨을 모읍니다 (아래 워크플로우) |
| JSON 내보내기 | | 모은 라벨을 파일로 다운로드 |

설정은 저장되며, 열려 있는 Bitget 탭에 바로 반영됩니다.

## 라벨 수집 → 사전 보강 워크플로우

1. 팝업에서 **초기화**를 누른 뒤 **라벨 수집**을 켭니다.
2. **로그인한 상태로** Bitget에서 평소 쓰는 화면을 돌아다닙니다: 선물/현물 주문 패널, 포지션·미체결·내역 탭, 자산 화면, 레버리지·증거금 모드·익절/손절 설정 창 등. **창을 직접 열어야** 그 안의 라벨이 수집됩니다.
   - 마켓 목록, 홈, 선물 정보 페이지는 종목명과 회사명이 수천 개라 노이즈만 늘어납니다. 거래 화면 위주로 다니세요.
   - 최대 5000개까지만 수집됩니다.
3. 팝업에서 **JSON 내보내기**를 누르면 `bitget-ko-labels-날짜-시간.json` 파일이 받아집니다.
   ```json
   {
     "Cost": "",
     "Max Open": "",
     "Size": ""
   }
   ```
   다음은 자동으로 빠집니다.
   - 숫자, 가격, 값이 박힌 텍스트 (`Limit: 1,000,000 USDT`)
   - 공백 없는 대문자 토큰: 코인 심볼, 거래쌍, 사용자 ID (`BTCUSDT`, `AUD/CAD`, `BGUSER-…`)
   - 이메일 주소 (로그인 시 화면에 보이는 본인 계정 등)
   - 한글/한자가 섞인 텍스트, 40자 넘는 문장
   - 이미 사전에 있는 라벨 (접미사 규칙으로 번역되는 것 포함)
   
   부작용으로 `GTC`, `BBO` 같은 UI 약어도 수집되지 않으므로, 약어는 화면을 보고 사전에 직접 넣어야 합니다.
4. 각 항목의 번역을 채웁니다.
   - 확신이 없으면 **지우고** `dictionary/UNSURE.md`에 후보와 함께 적습니다. 원칙은 정확성이 커버리지보다 우선입니다.
   - 잘못 누르면 손실이 나는 버튼(주문, 종료, 취소)은 `critical` 섹션에 넣어 원문을 병기합니다. 나머지는 `terms`에 넣습니다.
   - 용어 기준은 `dictionary/TERMS.md`의 "번역 원칙"을 따릅니다. 특히 **Close = 종료, 청산 = Liquidation 전용**입니다.
5. `dictionary/ko.json`에 붙여 넣고, `TERMS.md`에도 같은 카테고리로 한 줄씩 추가합니다.
6. 검증기를 돌립니다. 중복 키, 대소문자 충돌, TERMS.md 불일치를 잡아 줍니다. 수집 파일을 같이 넘기면 그중 몇 개가 번역되는지도 보여 줍니다.
   ```
   node test/check-dict.js 내보낸파일.json
   ```
7. `chrome://extensions`에서 Bitget KO의 새로고침(↻) 버튼을 누르고 Bitget 탭도 새로고침합니다.
8. 팝업에서 **초기화** 후 다시 수집합니다.

`ko.json` 형식:
```json
{
  "version": 2,
  "critical": { "Open Long": "롱 진입" },
  "terms":    { "Margin": "증거금" }
}
```
- 매칭할 때 대소문자는 무시합니다 (`Open long`도 `Open Long`으로 매칭).
- **접미사 규칙**: 정확 일치가 없으면 `사전키 (대문자 심볼 | 숫자 | 숫자h)` 형태 하나만 추가로 허용합니다. 괄호 앞부분만 번역하고 괄호는 그대로 둡니다.
  - 예: `Positions (0)` → `포지션 (0)`, `Price (USDT)` → `가격 (USDT)`, `Funding rate/Countdown (8h)` → `펀딩비/남은 시간 (8h)`
  - 개수가 `(0)` → `(3)`처럼 바뀌어도 다시 번역됩니다.
  - `(closed)` 같은 소문자 단어, `(UTC+8)` 같은 기호 괄호는 대상이 아닙니다.
- 하이픈과 공백은 구분하므로 `Reduce-only`와 `Reduce only`는 키를 각각 넣어야 합니다.
- 연속 공백과 앞뒤 공백은 무시합니다.

## 숫자 단위 한국식 규칙

같은 단위 안에서 표기만 바꿉니다. 환율 환산은 하지 않습니다.
- **대상**: 텍스트 전체가 `부호? $? 숫자 + K/M/B/T + (대문자 단위)?` 형태일 때만
  - 예: `1.41B`, `30K`, `-12.3K`, `$2.35B`, `1.5M USDT`
- **표기**:
  - K는 숫자 전체로: `30K` → `30,000`
  - M 이상은 만/억/조로: `150M` → `1.5억`, `1.23T` → `1.23조`
  - 원문의 유효자릿수를 유지합니다: `1.41B` → `14.1억`
- **제외**:
  - `1M`, `3M`처럼 한 자리 정수 + M (차트 기간 "개월" 버튼과 겹침)
  - 소문자 `15m`(분), 입력칸, 문장 속 숫자
- 원래 값은 마우스를 올리면 툴팁으로 보입니다.
- 토글을 끄면 숫자만 원래대로 돌아가고 번역은 유지됩니다.

## 원격 사전 업데이트 (zip 재배포 없이)

확장은 이 저장소의 `dictionary/ko.json`을 온라인으로 받아 내장 사전과 합칩니다. 사전만 고칠 때는 zip을 다시 줄 필요가 없습니다.

- 주소: `https://raw.githubusercontent.com/Kimdoeon52/BitGet_Translator/main/dictionary/ko.json`
- 1시간에 한 번 확인합니다. 팝업의 **지금 확인**을 누르면 즉시 확인합니다.
- 받은 사전은 열린 Bitget 탭에 새로고침 없이 바로 반영됩니다.
- 받기에 실패하거나 파일이 깨져 있으면 마지막으로 받은 정상 사전을 그대로 씁니다. 그것도 없으면 내장 사전만 씁니다.

**안전 규칙**
- 원격으로는 `terms`만 반영됩니다. `critical`(롱/숏, 진입/종료, 지정가/시장가 등 원문 병기 대상)은 원격으로 바꿀 수 없습니다.
- 원격 `terms`가 critical 키를 대소문자 변형(`Open long`)이나 접미사 형태(`Open Long (1)`)로 가로채는 것도 차단합니다.
- critical을 추가하거나 바꾸려면 새 zip을 배포해야 합니다.

**업데이트 순서**
1. `dictionary/ko.json`의 `terms`를 고치고 **`version`을 1 올립니다**. 원격 version이 내장보다 낮으면 무시됩니다.
2. `node test/check-dict.js`로 검증합니다.
3. 커밋하고 `main`에 push합니다.
4. 친구 쪽에는 최대 1시간 안에 반영됩니다. GitHub raw 캐시 때문에 push 직후 몇 분은 이전 파일이 내려올 수 있습니다.

## 테스트 (실제 사이트 없이)

`test/mock.html`은 Bitget 주문 패널을 흉내 낸 페이지입니다. 가격이 200ms마다 바뀌고, 테이블 재렌더와 행 추가도 일어납니다. 실제 `src/engine.js`와 `dictionary/ko.json`을 그대로 불러와 체크리스트를 자동으로 실행합니다.

```
node test/serve.js
```
브라우저에서 `http://localhost:8123/test/mock.html`을 엽니다 (`file://`로 열면 사전 로드가 막힙니다). Node.js가 필요합니다.

오른쪽 패널에서 다음을 확인할 수 있습니다.
- 체크리스트 결과 (PASS/FAIL)
  - 핵심 버튼 원문 병기, title 툴팁
  - 숫자/가격/심볼 미변경
  - 입력창·textarea·contenteditable·select 미변경
  - 부분 문자열 미치환
  - 동적 노드 치환 (재렌더, 행 추가, 값 교체)
  - 클릭 핸들러 유지
  - 원문 병기 ON/OFF, 번역 OFF 시 완전 원복
  - 라벨 수집 필터, flush 성능
- 번역 / 원문 병기 / 라벨 수집 토글을 직접 눌러보기
- flush 횟수와 소요 시간
- 수집된 라벨 목록

사전을 수정한 뒤에는 이 페이지에서 **다시 실행**을 눌러 깨진 게 없는지 확인하세요.

## 동작 원리 (요약)

- `src/engine.js`
  - TreeWalker로 텍스트 노드를 순회하고, 정규화한 전체 텍스트가 사전 키와 일치할 때만 `nodeValue`를 바꿉니다.
  - 알파벳이 없는 노드(가격, 퍼센트)는 정규식 한 번으로 즉시 건너뜁니다.
  - `input, textarea, select, option, script, style, [contenteditable]` 내부는 처리하지 않습니다.
  - 원문은 WeakMap에 보관합니다. 사이트가 같은 노드의 텍스트를 다시 바꾸면 새 원문으로 다시 판정합니다.
  - MutationObserver로 바뀐 노드만 모아서 `requestAnimationFrame` 단위로 처리합니다. 백그라운드 탭에서는 250ms 타이머로 대신합니다.
- `src/content.js`: 사전 로드(내장 + 원격 병합), 설정 반영, 수집 라벨 저장 (2초 간격, 최대 5000개).
- `src/background.js`: 원격 사전을 받아 검증한 뒤 저장 (서비스 워커).
- `popup/`: 설정 토글, 내보내기.

| 백그라운드 탭 | 보이지 않는 탭에서는 Chrome이 타이머를 1초 단위로 묶어서, 계속 다시 그려지는 영역은 영어로 남아 있을 수 있습니다. 탭을 다시 보면 그리기 전에 즉시 치환됩니다 |
| 사전 변경 반영 | ko.json을 고친 뒤에는 확장 새로고침과 탭 새로고침이 필요합니다. 확장만 새로고침하면 열려 있던 탭은 이전 버전으로 번역을 유지하지만, 팝업 설정 반영과 라벨 수집은 멈춥니다. 콘솔에 `[Bitget KO] 확장이 새로고침되었습니다` 안내가 나오면 탭을 새로고침하세요 |
| 수집 대상 | 화면에 실제로 렌더된 텍스트만 수집합니다. 열어보지 않은 창이나 툴팁은 수집되지 않습니다 |

## 배포 (테스트용 zip)

`dist/bitget-ko-v버전.zip`에는 확장 실행에 필요한 파일과 사용자용 안내문만 들어갑니다.
- 포함: `manifest.json`, `src/`, `popup/`, `dictionary/ko.json`, `dictionary/TERMS.md`, `시작하기.txt`
- 제외: `test/`, 수집 JSON 파일 (개인정보가 섞일 수 있음)

새 버전을 낼 때는 `manifest.json`의 `version`을 올린 뒤 같은 구성으로 다시 묶습니다.
